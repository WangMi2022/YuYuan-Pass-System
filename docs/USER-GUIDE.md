# YuYuan Pass System 用户使用手册

> 适用版本：2.9.2｜更新时间：2026-08-14

## 1. 文档说明

本文面向系统管理员、资产管理员、财务/票据人员、文档管理员和普通业务用户，说明系统登录、资产、发票、文档、工作日历、站点、公告、监控和权限配置的日常使用方法。

用户实际看到的菜单由角色权限决定。若本文提到的页面不可见，请先联系管理员确认菜单权限和 API 权限，而不是反复刷新或重新安装浏览器。

## 2. 登录与界面

### 2.1 登录

1. 在浏览器打开系统地址。
2. 输入用户名和密码。
3. 页面要求时输入验证码。
4. 点击“登录”。

连续登录失败可能触发验证码或防爆限制。账号被冻结、密码错误或角色未分配时，页面会显示对应提示。

登录页外观由管理员统一配置：桌面端重点展示背景图和品牌区域，移动端自动适配。管理员修改图标或背景后，刷新登录页即可看到最新效果。

### 2.2 导航结构

默认桌面布局使用顶部一级导航，当前主要入口为：

1. 首页驾驶舱。
2. 资产管理。
3. 流水管理。
4. 工作日历。
5. 协同办公。
6. 监控状态。
7. 权限管理。
8. 审计平台。
9. 系统管理。

系统配置允许用户切换侧边栏、双列导航、分页标签、主题和组件尺寸，因此不同账号看到的页面外壳可能略有不同，但功能路径不变。

### 2.3 顶部功能

- 导航：切换一级模块和子页面。
- 搜索：按名称搜索已授权菜单。
- 通知：查看未读公告和日程提醒。
- 主题：切换亮色与暗色模式。
- 系统配置：调整布局、尺寸、分页标签、水印与过渡效果。
- 用户菜单：个人信息、角色切换和退出。

## 3. 首页驾驶舱

菜单路径：`首页驾驶舱`。

首页用于快速掌握当前业务情况：

- 资产实物总量与档案数。
- 资产原值、当前估值和价值减少。
- 资产状态健康度。
- 最近登记资产。
- 资产流转草稿或待办。
- 今日及近期个人日程。

建议使用方式：

1. 每天登录后先查看状态异常和待办。
2. 点击指标或列表进入对应业务页处理。
3. 数据为空时先确认账号权限和是否已初始化演示/正式数据。

## 4. 资产管理

### 4.1 资产分类与位置

菜单路径：`资产管理 → 分类管理`。

页面包含七个页签：

- 资产分类。
- 入库位置。
- 使用位置。
- 调入位置。
- 归还位置。
- 维修位置。
- 处置位置。

### 新增分类

1. 切换到“资产分类”。
2. 点击“新增”。
3. 填写名称、编码和说明。
4. 选择展示颜色，设置排序和启用状态。
5. 保存。

分类编码应稳定且具有可读性。分类已经关联资产后，不建议随意修改编码或删除。

### 新增位置

1. 切换到对应业务位置页签。
2. 点击“新增位置”。
3. 填写位置名称、编码、说明和排序。
4. 设置是否启用。
5. 保存。

停用位置不会再出现在新业务单的选择列表中，但不会改变历史单据。临时位置可以在业务单中直接输入，不会自动写入字典。

### 4.2 资产档案

菜单路径：`资产管理 → 资产档案`。

### 新增资产

1. 点击“新增资产”。
2. 填写资产编号和名称。
3. 选择分类。
4. 填写品牌、型号和序列号。
5. 填写数量、单位、采购单价和当前估值。
6. 填写位置、保管人、供应商、购置日期和质保日期。
7. 上传需要的资产照片。
8. 填写备注并保存。

系统自动计算资产原值。新建资产状态是“待入库”，不会因为填写了位置就自动变为闲置；必须提交入库单。

### 查询资产

可按关键词、分类、状态、位置和价值范围筛选。常见状态：

- 待入库：已建档，未完成正式入库。
- 闲置：已入库，当前未领用。
- 使用中：已领用。
- 维修中：已进入维修流程。
- 已处置：已报废，当前估值为零。

### 编辑和删除

- 普通资料变更使用“编辑”。
- 状态、位置和保管人的正式业务变化应通过流转单完成，不建议直接改档案绕过审计。
- 已有正式流转记录的资产不能删除。
- 删除资产前确认图片、业务单和审计记录的影响。

### 4.3 智能建档

菜单路径：`资产管理 → 智能建档`。

1. 在“创建识别任务”区域选择 1-6 张清晰的资产照片或铭牌图片。
2. 点击“开始智能识别”，任务进入排队或识别中状态。
3. 任务变为“待确认”后打开详情，对照左侧图片、铭牌原文、字段置信度和警告。
4. 填写模型不会生成的资产编号、采购单价和当前估值，核对分类、序列号、规格和日期。
5. 点击“保存草稿”可暂存人工修正；点击“确认建档”才会创建正式资产。

使用规则：

- 支持 JPG、PNG、WebP、GIF，单张不超过 10 MB；同一任务最多 6 张。
- 低于 70% 的字段会明确标记为低置信度，不能只看模型结果跳过人工核对。
- 推荐分类必须映射到启用分类；未匹配时由用户选择。
- 序列号与现有资产完全匹配或标准化匹配时会显示重复候选，并阻止确认。
- 确认成功后任务与正式资产永久关联，不能再次确认或删除。
- 识别失败可以“重新识别”；状态为“待清理”表示临时图片未完全删除，只能重试删除，不能重新识别。
- AI Gateway、Vision Provider 或图片模块白名单未配置时，任务会显示明确失败；普通“新增资产”和资产流转不受影响。
- 当前 `asset-draft` Prompt V3 会把模型可能返回的 `productName`、`manufacturer`、`warrantyMonths` 自动归一为名称、品牌和建议质保月数；若标准字段和别名同时存在，以标准字段为准。用户无需手工处理字段名，但仍必须核对字段内容并人工确认。
- 模型只生成草稿。即使所有字段置信度较高，也只有点击“确认建档”且通过分类、必填项和重复校验后才会创建正式资产。

### 4.4 资产流转

菜单路径：

- `资产管理 → 入库管理`
- `资产管理 → 领用管理`
- `资产管理 → 调拨管理`
- `资产管理 → 归还管理`
- `资产管理 → 维修管理`
- `资产管理 → 报废管理`

### 通用操作

1. 进入对应业务页面。
2. 点击“新建业务单”。
3. 选择业务日期。
4. 根据业务填写目标位置、责任人或原因。
5. 搜索并选择资产，单张单据最多 100 项。
6. 填写备注。
7. 选择“保存草稿”或“提交”。

草稿不修改资产，可以继续编辑或删除；提交后立即更新资产状态，并生成不可变审计快照。

### 各业务规则

| 业务 | 可选资产 | 必填重点 | 提交结果 |
| --- | --- | --- | --- |
| 入库 | 待入库 | 目标位置 | 状态变为闲置 |
| 领用 | 闲置 | 责任人 | 状态变为使用中 |
| 调拨 | 闲置、使用中 | 目标位置 | 状态保持，位置变化 |
| 归还 | 使用中、维修中 | 目标位置 | 状态变为闲置，清空保管人 |
| 维修 | 闲置、使用中 | 原因 | 状态变为维修中 |
| 报废 | 闲置、使用中、维修中 | 原因 | 状态变为已处置，估值归零 |

如页面提示“当前状态不允许执行”，说明所选资产与当前业务类型不匹配，应返回档案或其他单据确认真实状态，不要直接修改数据库。

### 4.5 风险中心

菜单路径：`资产管理 → 风险中心`。

风险中心用于集中发现和处理状态、价值、归还与调拨、维修、质保和重复数据异常。规则结果是业务复核线索，不会自动提交流转、修改资产档案或报废资产。

### 查看总览

- 活动风险：待处理和已确认风险总数。
- 高风险：活动风险中的高风险和严重风险。
- 今日新增：当天首次发现的风险。
- 已逾期：首次发现超过 7 天仍未关闭的风险。
- 趋势与分布：查看最近 30 天新增/解决数量，以及类别、等级、状态和保管人分布。
- 最近扫描：查看运行状态、扫描资产数和新增/更新/关闭数量。

### 筛选和查看详情

1. 在事件列表按关键词、状态、等级、类别、规则或处理人筛选。
2. 点击风险打开详情。
3. 核对证据快照和建议动作。
4. 点击关联资产进入资产档案；页面会自动带入资产关键词。
5. 在处理时间线确认首次检出、分配和状态变更记录。

### 处理风险

| 动作 | 使用场景 | 规则 |
| --- | --- | --- |
| 确认 | 已接手，正在核查 | 可批量，说明可选 |
| 分配 | 指定启用用户处理 | 可批量，选择空处理人可取消分配 |
| 解决 | 已完成数据或业务修正 | 在详情中操作，必须填写说明 |
| 忽略 | 确认为可接受例外或误报 | 必须填写原因，只能逐条 |
| 重新打开 | 已关闭事件需要继续处理 | 在详情中操作，必须填写说明 |

扫描发现已解决风险再次命中时会自动重新打开；人工忽略的风险不会被扫描自动重开。高风险和严重风险首次发现、再次命中或分配时会进入顶部实时通知。

### 配置规则

1. 打开规则配置。
2. 修改风险等级、允许的阈值参数或启用状态。
3. 保存后确认版本号递增。
4. 手动启动扫描验证新版本结果。

规则编码和名称不可编辑。阈值变化会形成新版本风险事件，旧版本证据不会被覆盖。调整生产阈值前先查看命中规模，避免一次产生大量无效待办。

### 手动扫描和续扫

- 点击“立即扫描”启动全量扫描；同一时间只允许一个新鲜任务运行。
- 状态为 `running` 表示执行中，`success` 表示完成，`failed` 表示失败。
- 失败记录保留错误和资产游标，可在扫描记录中继续执行，不会从头重复已完成批次。
- 系统每天 `02:15` 自动扫描，服务启动后也会执行或恢复失败任务。

### 4.6 智能中心

菜单路径：`智能中心`，包含业务助手、智能日报和智能草稿三个页面。页面缺少菜单时，管理员需要同时给角色分配父菜单、子菜单和对应 `/smart/*`、`/smartReport/*` API 权限，然后重新登录刷新动态菜单。

#### 业务助手

1. 在输入框描述要查询的业务事实，例如“查看发票识别质量”“查询未来质保到期的资产”或“我有哪些未读公告”。
2. 发送后查看确定性查询结果、命中的 Tool、数据范围和引用。
3. 点击引用进入资产、发票、风险、日程或公告页面。
4. 使用左侧会话列表恢复历史问答；删除会话只删除本人会话和消息。

“可用 Tool”只显示当前角色同时具有原业务读取权限的查询。业务助手第一版是只读功能，不接受“帮我领用/报废/修改资产”等写操作指令。模型不可用时页面仍显示确定性查询结果；回答中的数字必须能在引用的业务列表中复核。

#### 智能日报

1. 打开页面查看资产流转、质保、风险、发票识别/确认金额、日程、公告以及 AI 失败率、耗时和费用指标。
2. 点击顶部指标卡进入对应业务列表；点击“生成今日日报”可以手动刷新，模型失败时仍保留结构化指标和跳转入口。
3. 在“日报订阅”中启用订阅并选择 `HH:MM` 发送时间。
4. `应用内` 会进入顶部通知；`邮件` 需要管理员先配置系统 SMTP 和用户邮箱。
5. 历史日报点击行后加载完整指标详情，不同用户不能互相查看日报和发送记录。

#### 智能草稿

公告编辑器中打开已发布公告，点击“提取日程草稿”，或在 `智能中心 → 智能草稿` 输入公告 ID。系统会提取日期、时间、地点、待办和原文证据；重复操作会复用同一用户已有草稿。

创建资产业务草稿时：

1. 选择业务类型，搜索并选择资产候选；也可以输入资产 ID。
2. 填写业务日期、目标位置、领用人和原因说明。
3. 点击生成后展开草稿，检查置信度、资产明细、业务字段和有效期。
4. 点击“确认写入”后，日程写入本人日历；资产业务只创建既有流转模块的草稿单。
5. 仍需到资产流转页面人工提交业务单；智能草稿不会自动领用、报废、维修或改变资产主表。

草稿过期、资产不存在、业务类型不允许或当前用户缺少智能 API 或原 `/assetOperation/*`、`/workSchedule/create` 权限时，服务端会拒绝确认。过期的公告日程草稿可再次提取，系统会刷新原草稿而不是新建重复记录。确认过程中的草稿显示为处理中，避免重复点击创建两张业务单。

## 5. 流水管理

### 5.1 流水总览

菜单路径：`流水管理 → 流水总览`。

用于查看已确认发票形成的正式统计，包括金额、分类、方向、趋势和近期记录。只有状态为“已确认”的发票进入正式统计；待复核、识别中和识别失败的数据不计入。

### 5.2 发票识别

菜单路径：`流水管理 → 发票识别`。

### 上传发票

1. 点击上传区域或选择文件。
2. 可选择单个或多个文件。
3. 等待上传完成。
4. 系统根据当前能力配置执行 OCR 或多模态识别。
5. 查看每张发票的识别状态。

常见状态：

- 已上传：文件已保存，任务准备中。
- 识别中：后台正在处理。
- 待复核：识别完成，需要人工检查。
- 识别失败：查看错误后重试。
- 已确认：已进入正式台账和统计。

如果系统提示识别能力不可用，请管理员在运行配置中检查提供方开关、Endpoint、API Key 和网络访问。

### 批量上传建议

- 使用清晰、方向正确的原始 PDF 或图片。
- 避免同一张发票重复上传。
- 大批量处理时分批上传并等待任务完成，便于定位失败文件。
- 上传后不要立即关闭页面；即使关闭，后台任务仍会保留，但稍后需要在台账查看结果。

### 5.3 发票台账

菜单路径：`流水管理 → 发票台账`。

### 筛选

可按状态、分类、流水方向和日期范围筛选。点击记录查看原始文件、识别字段、发票明细和验真历史。

### 人工复核

1. 打开待复核发票。
2. 对照原始文件检查发票类型、代码、号码和开票日期。
3. 检查购买方、销售方和税号。
4. 检查不含税金额、税额和价税合计。
5. 检查明细行。
6. 选择分类并填写复核备注。
7. 保存修改。

页面金额以元展示，服务端以分存储。不要通过四舍五入强行修正原始票面不一致，应回到明细或原文件确认。

### 验真

在部署环境已配置验真服务时：

1. 打开发票详情。
2. 点击“验真”。
3. 查看有效、作废、红冲、不一致、未找到或服务不可用等结果。
4. 查看验真历史和字段差异。

如果验真暂不可用，系统不应把“未验真”误显示为“有效”。确需绕过验真确认时，按组织权限和流程填写明确原因。

### 确认和重开

- “确认”会把发票纳入正式统计并启用防重。
- 已确认发票不能直接修改。
- 需要纠正时由管理员执行“重开”，返回待复核后再编辑。
- 重复关键票据确认会被拒绝，应检查是否已存在同一发票。

### 删除

删除前确认发票未被业务流程引用。系统会删除业务记录并创建对象存储清理任务；若对象存储临时不可用，后台任务会重试。

### 5.4 分类规则

菜单路径：`流水管理 → 分类规则`。

页面用于维护：

- 发票分类：名称、编码、颜色、说明、排序和启用。
- 分类规则：匹配字段、关键词、目标分类、优先级、分值和启用。

建议从明确、稳定的供应商或票种规则开始，避免过宽关键词导致误分类。人工选择的分类应作为最终复核结果。

### 5.5 发票识别质量

菜单路径：`流水管理 → 发票识别质量`。

- 使用日期、Provider、模型和文件类型筛选同一批质量数据。
- 总览卡片查看成功率、失败率、平均耗时、平均尝试、回退率、人工复核量和估算费用。
- Provider 表用于比较不同 Provider、模型和文件类型的稳定性。
- 字段质量表显示复核量、人工修改率、未修改准确率口径和平均置信度。
- 失败明细用于定位提供方、模型、重试次数和错误摘要。
- 分类效果显示推荐被接受、被推翻和仍待复核的数量。

“字段准确率”表示已进入字段级复核采集的数据中，该字段未被人工修改的比例，不等同于权威验真结果。历史发票若没有字段级修正来源，会单独显示为“历史无字段级修正数据”，不会被系统猜测成正确或错误。

功能上线后，只有保存过人工复核的新数据才会逐步产生字段修改率。若字段质量表暂时为空，应先确认筛选时间范围内是否已有发票进入复核采集，而不是把空数据判断为接口故障。

## 6. 工作日历

菜单路径：`工作日历 → 日程总览`。

### 新建日程

1. 点击“新建日程”，或点击月历中的日期。
2. 填写日程名称。
3. 选择日期和时间。
4. 选择日程类型。
5. 填写备注。
6. 需要时启用重复日程。
7. 保存。

### 重复日程

支持：

- 每日。
- 每周，可选择星期。
- 每月，可选择月内日期。

修改重复规则后只影响该日程后续计算。删除日程后，不再生成新的提醒；已经生成的历史通知按收件箱状态保留或由系统策略清理。

### 日程类型

页面可维护个人使用的日程类型、名称和颜色。已被日程使用的类型不能直接删除；至少保留一个类型。

### 提醒

到期提醒会进入顶部通知或日程通知列表。支持单条已读和全部已读。提醒按用户隔离，不会显示其他用户的私人日程。

### 旧数据导入

系统检测到旧版本浏览器本地日程时，可执行一次性导入。服务端使用客户端标识去重，重复导入不会无限创建相同数据。

## 7. 文档管理

菜单路径：`协同办公 → 文档管理`。

### 支持能力

- Word：预览，按页面能力进入在线内容编辑。
- Excel：预览和表格编辑。
- PDF：源文件预览。
- Markdown、文本：预览与编辑。
- 其他格式：保存元数据并下载原文件，是否可在线编辑以页面提示为准。

### 上传文档

1. 点击“上传文档”。
2. 选择文件。
3. 等待对象存储上传完成。
4. 在列表确认标题、扩展名、大小和时间。

### 查看源文件

打开文档详情后先查看源文件。大文档首次加载需要时间，不要在加载中重复点击上传或删除。

### 在线编辑

1. 确认当前格式支持编辑。
2. 点击“开始编辑”。
3. 修改内容、标题或备注。
4. 点击保存。

在线保存不会覆盖原始文件。如需替换证据文件，应上传新文档并按组织规则处理旧记录。

### 删除文档

删除会影响数据库记录和对象文件。删除前确认没有其他页面或公告引用该文件。

- 离线用户下次登录后看到未读。

## 12. 权限管理

### 12.1 用户管理

菜单路径：`权限管理 → 用户管理`。

管理员可以新增、编辑、冻结用户，设置角色和重置密码。冻结用户前确认业务交接和个人日程数据处理方式。

### 12.2 角色管理

菜单路径：`权限管理 → 角色管理`。

一个完整角色通常需要同时分配：

1. 菜单权限：能否看到页面。

### 12.3 菜单和 API 管理

- 菜单管理维护动态路由、组件路径、图标、排序和显隐。
- API 管理维护后端路径、方法和分组。
- 修改后应为相关角色重新分配并重新登录验证。
- 不要删除系统和插件仍在使用的 API 定义。

## 14. AI 运营

菜单路径：`AI 运营`。默认仅超级管理员可见；其他角色需要同时分配菜单权限和 `/ai/*` API 权限。

### 14.1 Provider

1. 选择 OpenAI Compatible 或 Anthropic，填写 Base URL、模型和超时。
2. 第一次配置时输入 API Key；后续留空会保留现有密钥。
3. 按供应商账单填写每百万输入、输出 Token 的费用微单位。
4. 按需维护业务敏感词和允许发送图片的模块标识。
5. 保存后确认页面只显示“已配置”，不会回显密钥。

私有、回环和内网 Endpoint 默认禁止。只有使用受控企业内网模型时才启用“允许内网端点”。Gateway 总开关关闭时，新 AI 能力不可调用；现有自动代码兼容服务仍使用原 `autocode.ai-path`。

### 14.2 调用审计与用量

- 页面顶部展示当前账户今日调用、Token、本月估算费用和累计调用。
- 调用审计可按状态、业务模块和 Provider 查询。
- `blocked` 表示权限、配额、开关、输入或策略阻断；`failed` 表示 Provider、超时、读取或 Schema 失败。
- 审计只保存摘要和哈希，不保存原始 Prompt、图片和模型输出。

### 14.3 配额

配额范围支持全局、模块、角色和用户。所有匹配的启用配额同时生效；值为 0 表示该指标不限制。配置前先确认月度预算单位和 Provider 费用单价，避免把“微单位”误当成人民币元。

### 14.4 Prompt

新建 Prompt 会生成递增的草稿版本。可选 `outputSchema` 必须是合法 JSON Schema。激活新版本后旧活跃版本自动退役；历史版本保留用于审计和显式回放。不要在 Prompt 中写入 API Key、密码或长期凭据。

## 16. 常见问题

### 页面白屏或动态模块加载失败

1. 使用 `Ctrl + F5` 强制刷新。
2. 清理当前站点缓存。
3. 确认 Web 已部署最新版本。
4. 检查缺失的 `/assets/*.js` 是否返回 404，而不是 HTML。

### 看不到菜单

- 退出并重新登录，刷新动态菜单。
- 检查角色的父菜单、子菜单和 API 权限。
- 检查菜单组件路径是否存在。

### 请求提示无权限

页面可见但接口无权限通常是角色缺少 API 权限。记录请求路径和 HTTP 方法，交给管理员在角色权限中补齐。

### 图片或文档加载失败

- 检查对象存储和目标桶。
- 检查 Endpoint、Bucket、对象前缀和访问策略。
- 确认应用连接的是 S3 API 端口，通常为 9000，不是管理控制台 9001。
- 私有文件确认当前账号拥有数据权限。

### 发票一直识别中或失败

- 查看识别能力状态。
- 检查外部提供方配置和网络。
- 使用清晰文件重试。
- 查看 Server 日志和识别任务失败详情。

### 发票无法确认

- 检查必填字段和金额。
- 检查验真结果是否阻止确认。
- 检查是否存在重复已确认发票。
- 已确认发票需要先由管理员重开。

### 智能建档任务失败或无法确认

- 失败时先查看任务详情中的错误；Provider、模型、API Key 或图片白名单问题由管理员处理后再重试。
- Schema 错误表示模型输出不符合结构约束，可重试或调整已激活的 `asset-draft` Prompt/模型。V3 只兼容 `productName`、`manufacturer`、`warrantyMonths` 三个别名，其他未知字段仍会被拒绝。
- 无法确认时检查资产编号、名称、分类、数量、价格、日期和重复序列号候选。
- “待清理”不是识别失败，说明删除图片时存储暂不可用；恢复对象存储后点击“重试删除”。

### AI 调用被阻断或失败

- 检查 Gateway 与目标 Provider 是否启用。
- 检查当前角色的业务 API 权限、模块/角色/用户配额和并发上限。
- 图片调用检查模块是否在图片外发白名单，MIME 是否为 JPEG、PNG、WebP 或 GIF。
- Schema 失败时检查 Prompt 的输出约束和模型实际 JSON。
- Provider 鉴权失败时重新写入 API Key；页面不会回显旧密钥。

### 风险扫描未启动、长时间运行或失败

- 检查扫描记录是否已有 `running` 任务；系统会阻止并发扫描。
- 资产量较大时观察心跳、已扫描数量和游标是否持续变化，不要重复点击。
- `failed` 任务查看错误详情后执行续扫；自动恢复最多尝试 3 次。
- 页面可见但扫描或处理提示无权限时，为角色补齐对应 `/assetRisk/*` 方法权限并重新登录。

### 已处理风险再次出现

- 已解决风险再次满足同一规则时会自动重开，这是正常行为。
- 已忽略风险不会被扫描自动重开；需要重新处理时由用户填写说明后人工重开。
- 规则版本变更会保留旧证据并产生新版本事件，应按当前规则重新复核。

### 收不到公告或日程提醒

- 确认浏览器通知区域正常刷新。
- 公告必须是已发布状态。
- 检查 `/api/info/stream` 是否被代理中断。
- 即使实时连接断开，刷新通知列表仍应恢复未读。

### Excel 编辑卡顿

- 大文件首次解析需要时间。
- 先使用源文件预览，确认确实需要编辑后再进入编辑器。
- 减少超大图片、复杂合并单元格和无用空白行。
