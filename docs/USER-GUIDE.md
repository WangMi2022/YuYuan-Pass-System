# YuYuan Pass System 用户使用手册

> 适用版本：2.9.2｜更新时间：2026-08-13

## 1. 文档说明

本文面向系统管理员、资产管理员、财务/票据人员、文档管理员和普通业务用户，说明系统登录、资产、发票、文档、工作日历、站点、公告、监控和权限配置的日常使用方法。

用户实际看到的菜单由角色权限决定。若本文提到的页面不可见，请先联系管理员确认菜单权限和 API 权限，而不是反复刷新或重新安装浏览器。

## 2. 登录与界面

### 2.1 登录

1. 在浏览器打开系统地址。
2. 输入用户名和密码。
3. 页面要求时输入验证码。
4. 点击“登录”。

连续登录失败可能触发验证码或防爆限制。账号被冻结、密码错误或角色未分配时，页面会显示对应提示。

登录页外观由管理员统一配置：桌面端重点展示背景图和品牌区域，移动端自动适配。管理员修改图标或背景后，刷新登录页即可看到最新效果。

### 2.2 导航结构

默认桌面布局使用顶部一级导航，当前主要入口为：

1. 首页驾驶舱。
2. 资产管理。
3. 流水管理。
4. 工作日历。
5. 协同办公。
6. 监控状态。
7. 权限管理。
8. 审计平台。
9. 系统管理。

系统配置允许用户切换侧边栏、双列导航、分页标签、主题和组件尺寸，因此不同账号看到的页面外壳可能略有不同，但功能路径不变。

### 2.3 顶部功能

- 导航：切换一级模块和子页面。
- 搜索：按名称搜索已授权菜单。
- 通知：查看未读公告和日程提醒。
- 主题：切换亮色与暗色模式。
- 系统配置：调整布局、尺寸、分页标签、水印与过渡效果。
- 用户菜单：个人信息、角色切换和退出。

## 3. 首页驾驶舱

菜单路径：`首页驾驶舱`。

首页用于快速掌握当前业务情况：

- 资产实物总量与档案数。
- 资产原值、当前估值和价值减少。
- 资产状态健康度。
- 最近登记资产。
- 资产流转草稿或待办。
- 今日及近期个人日程。

建议使用方式：

1. 每天登录后先查看状态异常和待办。
2. 点击指标或列表进入对应业务页处理。
3. 数据为空时先确认账号权限和是否已初始化演示/正式数据。

## 4. 资产管理

### 4.1 资产分类与位置

菜单路径：`资产管理 → 分类管理`。

页面包含七个页签：

- 资产分类。
- 入库位置。
- 使用位置。
- 调入位置。
- 归还位置。
- 维修位置。
- 处置位置。

### 新增分类

1. 切换到“资产分类”。
2. 点击“新增”。
3. 填写名称、编码和说明。
4. 选择展示颜色，设置排序和启用状态。
5. 保存。

分类编码应稳定且具有可读性。分类已经关联资产后，不建议随意修改编码或删除。

### 新增位置

1. 切换到对应业务位置页签。
2. 点击“新增位置”。
3. 填写位置名称、编码、说明和排序。
4. 设置是否启用。
5. 保存。

停用位置不会再出现在新业务单的选择列表中，但不会改变历史单据。临时位置可以在业务单中直接输入，不会自动写入字典。

### 4.2 资产档案

菜单路径：`资产管理 → 资产档案`。

### 新增资产

1. 点击“新增资产”。
2. 填写资产编号和名称。
3. 选择分类。
4. 填写品牌、型号和序列号。
5. 填写数量、单位、采购单价和当前估值。
6. 填写位置、保管人、供应商、购置日期和质保日期。
7. 上传需要的资产照片。
8. 填写备注并保存。

系统自动计算资产原值。新建资产状态是“待入库”，不会因为填写了位置就自动变为闲置；必须提交入库单。

### 查询资产

可按关键词、分类、状态、位置和价值范围筛选。常见状态：

- 待入库：已建档，未完成正式入库。
- 闲置：已入库，当前未领用。
- 使用中：已领用。
- 维修中：已进入维修流程。
- 已处置：已报废，当前估值为零。

### 编辑和删除

- 普通资料变更使用“编辑”。
- 状态、位置和保管人的正式业务变化应通过流转单完成，不建议直接改档案绕过审计。
- 已有正式流转记录的资产不能删除。
- 删除资产前确认图片、业务单和审计记录的影响。

### 4.3 资产流转

菜单路径：

- `资产管理 → 入库管理`
- `资产管理 → 领用管理`
- `资产管理 → 调拨管理`
- `资产管理 → 归还管理`
- `资产管理 → 维修管理`
- `资产管理 → 报废管理`

### 通用操作

1. 进入对应业务页面。
2. 点击“新建业务单”。
3. 选择业务日期。
4. 根据业务填写目标位置、责任人或原因。
5. 搜索并选择资产，单张单据最多 100 项。
6. 填写备注。
7. 选择“保存草稿”或“提交”。

草稿不修改资产，可以继续编辑或删除；提交后立即更新资产状态，并生成不可变审计快照。

### 各业务规则

| 业务 | 可选资产 | 必填重点 | 提交结果 |
| --- | --- | --- | --- |
| 入库 | 待入库 | 目标位置 | 状态变为闲置 |
| 领用 | 闲置 | 责任人 | 状态变为使用中 |
| 调拨 | 闲置、使用中 | 目标位置 | 状态保持，位置变化 |
| 归还 | 使用中、维修中 | 目标位置 | 状态变为闲置，清空保管人 |
| 维修 | 闲置、使用中 | 原因 | 状态变为维修中 |
| 报废 | 闲置、使用中、维修中 | 原因 | 状态变为已处置，估值归零 |

如页面提示“当前状态不允许执行”，说明所选资产与当前业务类型不匹配，应返回档案或其他单据确认真实状态，不要直接修改数据库。

## 5. 流水管理

### 5.1 流水总览

菜单路径：`流水管理 → 流水总览`。

用于查看已确认发票形成的正式统计，包括金额、分类、方向、趋势和近期记录。只有状态为“已确认”的发票进入正式统计；待复核、识别中和识别失败的数据不计入。

### 5.2 发票识别

菜单路径：`流水管理 → 发票识别`。

### 上传发票

1. 点击上传区域或选择文件。
2. 可选择单个或多个文件。
3. 等待上传完成。
4. 系统根据当前能力配置执行 OCR 或多模态识别。
5. 查看每张发票的识别状态。

常见状态：

- 已上传：文件已保存，任务准备中。
- 识别中：后台正在处理。
- 待复核：识别完成，需要人工检查。
- 识别失败：查看错误后重试。
- 已确认：已进入正式台账和统计。

如果系统提示识别能力不可用，请管理员在运行配置中检查提供方开关、Endpoint、API Key 和网络访问。

### 批量上传建议

- 使用清晰、方向正确的原始 PDF 或图片。
- 避免同一张发票重复上传。
- 大批量处理时分批上传并等待任务完成，便于定位失败文件。
- 上传后不要立即关闭页面；即使关闭，后台任务仍会保留，但稍后需要在台账查看结果。

### 5.3 发票台账

菜单路径：`流水管理 → 发票台账`。

### 筛选

可按状态、分类、流水方向和日期范围筛选。点击记录查看原始文件、识别字段、发票明细和验真历史。

### 人工复核

1. 打开待复核发票。
2. 对照原始文件检查发票类型、代码、号码和开票日期。
3. 检查购买方、销售方和税号。
4. 检查不含税金额、税额和价税合计。
5. 检查明细行。
6. 选择分类并填写复核备注。
7. 保存修改。

页面金额以元展示，服务端以分存储。不要通过四舍五入强行修正原始票面不一致，应回到明细或原文件确认。

### 验真

在部署环境已配置验真服务时：

1. 打开发票详情。
2. 点击“验真”。
3. 查看有效、作废、红冲、不一致、未找到或服务不可用等结果。
4. 查看验真历史和字段差异。

如果验真暂不可用，系统不应把“未验真”误显示为“有效”。确需绕过验真确认时，按组织权限和流程填写明确原因。

### 确认和重开

- “确认”会把发票纳入正式统计并启用防重。
- 已确认发票不能直接修改。
- 需要纠正时由管理员执行“重开”，返回待复核后再编辑。
- 重复关键票据确认会被拒绝，应检查是否已存在同一发票。

### 删除

删除前确认发票未被业务流程引用。系统会删除业务记录并创建对象存储清理任务；若对象存储临时不可用，后台任务会重试。

### 5.4 分类规则

菜单路径：`流水管理 → 分类规则`。

页面用于维护：

- 发票分类：名称、编码、颜色、说明、排序和启用。
- 分类规则：匹配字段、关键词、目标分类、优先级、分值和启用。

建议从明确、稳定的供应商或票种规则开始，避免过宽关键词导致误分类。人工选择的分类应作为最终复核结果。

## 6. 工作日历

菜单路径：`工作日历 → 日程总览`。

### 新建日程

1. 点击“新建日程”，或点击月历中的日期。
2. 填写日程名称。
3. 选择日期和时间。
4. 选择日程类型。
5. 填写备注。
6. 需要时启用重复日程。
7. 保存。

### 重复日程

支持：

- 每日。
- 每周，可选择星期。
- 每月，可选择月内日期。

修改重复规则后只影响该日程后续计算。删除日程后，不再生成新的提醒；已经生成的历史通知按收件箱状态保留或由系统策略清理。

### 日程类型

页面可维护个人使用的日程类型、名称和颜色。已被日程使用的类型不能直接删除；至少保留一个类型。

### 提醒

到期提醒会进入顶部通知或日程通知列表。支持单条已读和全部已读。提醒按用户隔离，不会显示其他用户的私人日程。

### 旧数据导入

系统检测到旧版本浏览器本地日程时，可执行一次性导入。服务端使用客户端标识去重，重复导入不会无限创建相同数据。

## 7. 文档管理

菜单路径：`协同办公 → 文档管理`。

### 支持能力

- Word：预览，按页面能力进入在线内容编辑。
- Excel：预览和表格编辑。
- PDF：源文件预览。
- Markdown、文本：预览与编辑。
- 其他格式：保存元数据并下载原文件，是否可在线编辑以页面提示为准。

### 上传文档

1. 点击“上传文档”。
2. 选择文件。
3. 等待对象存储上传完成。
4. 在列表确认标题、扩展名、大小和时间。

### 查看源文件

打开文档详情后先查看源文件。大文档首次加载需要时间，不要在加载中重复点击上传或删除。

### 在线编辑

1. 确认当前格式支持编辑。
2. 点击“开始编辑”。
3. 修改内容、标题或备注。
4. 点击保存。

在线保存不会覆盖原始文件。如需替换证据文件，应上传新文档并按组织规则处理旧记录。

### 删除文档

删除会影响数据库记录和对象文件。删除前确认没有其他页面或公告引用该文件。

## 8. 站点收藏

菜单路径：`协同办公 → 站点收藏`。

### 新增站点

1. 点击“新增站点”。
2. 填写名称和 HTTP/HTTPS 地址。
3. 选择分类、颜色、排序和启用状态。
4. 填写用途说明。
5. 保存。

点击站点卡片或“打开”会在新窗口访问，并累计访问次数和最近访问时间。

### 维护站点

- 按名称、地址、分类或说明搜索。
- 按分类和启用状态筛选。
- 停用站点保留记录，但不再作为正常工作入口。
- 删除前确认该入口不再使用。

## 9. 公告管理与通知

菜单路径：`协同办公 → 公告管理`。

### 查看公告

顶部通知区域显示未读公告。点击公告后打开详情并标记已读；“全部已读”会清除当前用户的未读状态。

已读状态保存在服务端，因此更换浏览器或设备后仍保持一致。

### 发布公告

1. 点击“发布公告”或“新增”。
2. 填写标题和正文。
3. 根据需要添加附件。
4. 保存草稿，或直接发布。

只有已发布公告才会进入通知链路：

- 在线用户通过 SSE 收到实时提醒。
- 离线用户下次登录后看到未读。
- SSE 暂时断开时，客户端仍会通过通知列表补偿。

## 10. 媒体库

菜单路径：`协同办公 → 媒体库`。

- 只上传图片。
- 上传前压缩超大图片，避免加载缓慢。
- 不上传包含敏感信息但不应公开展示的截图。
- 删除前确认图片未被头像、资产、公告、文档或登录外观引用。

## 11. 监控状态

菜单路径：`监控状态 → 服务器负载`。

页面展示：

- CPU 平均使用率与逻辑核心负载。
- 内存容量和使用率。
- 1、5、15 分钟系统负载。
- 各挂载点磁盘容量与使用率。
- 主机、内核、Go runtime、Goroutine 和运行时长。
- 当前页面最近 30 次采样趋势。

可以切换 5、10、30、60 秒采样间隔，暂停或手动刷新。趋势数据只保留在当前页面，刷新后重新开始。

## 12. 权限管理

### 12.1 用户管理

菜单路径：`权限管理 → 用户管理`。

管理员可以新增、编辑、冻结用户，设置角色和重置密码。冻结用户前确认业务交接和个人日程数据处理方式。

### 12.2 角色管理

菜单路径：`权限管理 → 角色管理`。

一个完整角色通常需要同时分配：

1. 菜单权限：能否看到页面。
2. API 权限：能否调用后端接口。
3. 按钮权限：页面中的细粒度操作。

只分配菜单不分配 API，会出现“页面可见但请求无权限”。

### 12.3 菜单和 API 管理

- 菜单管理维护动态路由、组件路径、图标、排序和显隐。
- API 管理维护后端路径、方法和分组。
- 修改后应为相关角色重新分配并重新登录验证。
- 不要删除系统和插件仍在使用的 API 定义。

## 13. 审计平台

### 操作历史

记录关键新增、修改、删除和配置操作，可按路径、状态、用户和时间查询。

### 登录日志

记录登录成功和失败，用于排查账号、密码、验证码、IP 和客户端问题。

### 错误日志

记录系统运行异常。排障时同时结合容器日志、请求时间和操作历史，不只看页面提示。

## 14. 系统管理

### 14.1 字典与参数

字典用于系统通用选项，参数用于运行时业务配置。修改前确认是否影响已有页面或初始化逻辑。

### 14.2 API Token

用于受控系统集成。令牌只授予必要权限，设置有效期并定期轮换；不得在聊天、截图或仓库中公开。

### 14.3 系统设置

菜单路径：`系统管理 → 系统设置`。

#### 更换登录图标

1. 查看当前图标。
2. 点击上传并应用。
3. 选择 JPG、PNG 或 WebP。
4. 等待上传完成。

建议使用正方形、主体居中的图片，单张不超过 2 MB。可点击恢复默认。

#### 更换登录背景

1. 进入背景变更管理。
2. 上传 JPG、PNG 或 WebP。
3. 在图库中选中目标背景。
4. 点击保存并应用。

上传只会加入图库，必须激活后才改变登录页。正在使用的背景不能删除。

## 15. 常见问题

### 页面白屏或动态模块加载失败

1. 使用 `Ctrl + F5` 强制刷新。
2. 清理当前站点缓存。
3. 确认 Web 已部署最新版本。
4. 检查缺失的 `/assets/*.js` 是否返回 404，而不是 HTML。

### 看不到菜单

- 退出并重新登录，刷新动态菜单。
- 检查角色的父菜单、子菜单和 API 权限。
- 检查菜单组件路径是否存在。

### 请求提示无权限

页面可见但接口无权限通常是角色缺少 API 权限。记录请求路径和 HTTP 方法，交给管理员在角色权限中补齐。

### 图片或文档加载失败

- 检查对象存储和目标桶。
- 检查 Endpoint、Bucket、对象前缀和访问策略。
- 确认应用连接的是 S3 API 端口，通常为 9000，不是管理控制台 9001。
- 私有文件确认当前账号拥有数据权限。

### 发票一直识别中或失败

- 查看识别能力状态。
- 检查外部提供方配置和网络。
- 使用清晰文件重试。
- 查看 Server 日志和识别任务失败详情。

### 发票无法确认

- 检查必填字段和金额。
- 检查验真结果是否阻止确认。
- 检查是否存在重复已确认发票。
- 已确认发票需要先由管理员重开。

### 收不到公告或日程提醒

- 确认浏览器通知区域正常刷新。
- 公告必须是已发布状态。
- 检查 `/api/info/stream` 是否被代理中断。
- 即使实时连接断开，刷新通知列表仍应恢复未读。

### Excel 编辑卡顿

- 大文件首次解析需要时间。
- 先使用源文件预览，确认确实需要编辑后再进入编辑器。
- 减少超大图片、复杂合并单元格和无用空白行。

## 16. 退出系统

点击用户菜单选择“退出登录”。公共或共享电脑使用完毕后必须退出账号并关闭浏览器，不要只关闭业务标签页。
